Quick Mod

Haven's MirrorCustom Dialogue Busts

Your face in the conversation

v1.0.0
Thunderstore — Nexus Mods — Combined —

Haven's Mirror lets you show a custom player bust during dialogue by dropping PNG files into a gallery folder. Optional config can force a look for NPC portraits and seasonal outfits. Reload portraits with a hotkey — no restart required.

Features

🖼️

PNG Gallery

Per-character folders under gallery/, with a shared fallback. Missing slots reuse the first PNG found.

🌸

Season & Special Looks

Spring, summer, autumn, winter, vows, shore, and costume files map to dialogue contexts.

🔄

Hotkey Reload

Press Ctrl+F8 (configurable) to reload PNGs from disk while playing.

🎭

Forced Look

Optional override keeps NPC dialogue busts (and seasonal body outfits) on a look you choose.

Portrait files

When the game runs, Haven's Mirror reads your character saves and creates empty gallery/<CharacterName>/ folders for you. Empty folders are ignored until you add PNGs. You can also use gallery/_shared/ as a fallback:

  • spring.png — default / spring
  • summer.png, autumn.png, winter.png
  • vows.png — wedding / ceremony
  • shore.png — swimsuit / beach
  • costume.png — halloween / costume

Configuration

BepInEx/config/HavensMirror.cfg
Setting Default Description
Enabled true Master switch
GalleryFolderName gallery Folder under the plugin directory for portraits
SharedFolderName _shared Fallback folder when the character folder is empty
ForcedLook (blank) Spring / Summer / Autumn / Winter / Vows / Shore / Costume
ReloadModifier + ReloadKey LeftControl + F8 Reload PNGs from disk

Installation

📦

1. Install BepInEx

Install BepInEx 5.x for Sun Haven if you haven't already.

📥

2. Download Haven's Mirror

Get HavensMirror.dll from Nexus Mods, GitHub Releases, or Thunderstore when published — or build from this repo.

📁

3. Install & add portraits

Place the DLL in BepInEx/plugins/HavensMirror/, then drop PNGs into gallery/_shared/ or a character-named subfolder.
