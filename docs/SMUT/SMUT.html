S.M.U.T.Sun Haven Museum Utility Tracker

Track Your Museum Donations

v2.1.1

S.M.U.T. helps you track which items you've donated to the Sun Haven Museum and which ones you still need. With per-character saves, search functionality, and a beautiful dark-themed UI organized by museum sections and bundles, you'll never lose track of your collection progress again.

What's New in v2.1.1

✨

UI Updates

Improved visual styling and layout refinements for a cleaner, more polished experience.

🐛

Bug Fixes

Various bug fixes and stability improvements for smoother tracking.

🔄 Smart Tracking

S.M.U.T. now features real-time auto-tracking! When you donate items to museum bundles in-game, they're automatically marked in your tracker. Plus, use the "Sync with Game" button to import all completed bundles from your save file.

Bundle headers show both your tracked progress and the game's recorded donation count [Game: X] side-by-side!

Key Features

🔄

Real-Time Auto-Tracking

Donations are automatically tracked when you add items to museum bundles. No need to manually check boxes for new donations!

🔗

Sync with Game

Click "Sync with Game" to import all completed bundles from your save file. Bundle headers show game progress alongside your tracked items.

👤

Per-Character Saves

Each character has their own separate donation tracker. Switch between characters and your progress is always saved correctly.

🔍

Search & Filter

Search for items by name or rarity. Toggle "Show only needed" to hide donated items and focus on what's missing.

📊

Progress Statistics

See completion percentages for each section, bundle, and your overall museum progress. Progress bars show exactly how close you are to 100%.

💎

Rarity Colors

Items are color-coded by rarity (Common, Uncommon, Rare, Epic, Legendary) so you can prioritize finding those rare collectibles.

How to Use

1

Open the Tracker

Press Ctrl + C to open the Museum Tracker window. Press Escape or the X button to close it.

2

Choose a Section

Click the tabs at the top to switch between The Hall of Gems, The Hall of Culture, and the Aquarium.

3

Search or Filter

Use the search box to find specific items, or toggle "Show needed only" to hide already donated items.

4

Expand Bundles

Click on any bundle header to expand it and see all the items within that category.

5

Mark Donations

Click the checkbox next to any item to mark it as donated. Items you donate in-game are auto-tracked!

6

Sync with Game

Click the "Sync with Game" button to import completed bundles from your save. The [Game: X] indicator shows the game's recorded donation count.

Installation

📦

1. Install BepInEx

Download and install BepInEx 5.x for Unity games if you haven't already.

📥

2. Download S.M.U.T.

Get SunHavenMuseumUtilityTracker.dll from Nexus Mods.

📁

3. Install the Mod

Place the DLL in your BepInEx/plugins/ folder.

🎮

4. Play!

Launch Sun Haven and press Ctrl+C to track your museum progress.

Configuration

Setting Default Description
ToggleKey C Key to open/close the tracker UI
RequireCtrl true Require Ctrl key when pressing toggle key
AltToggleKey F7 Alternative key to toggle tracker (no modifier required, great for Steam Deck)

Configuration file located at: BepInEx/config/com.azraelgodking.sunhavenmuseumutilitytracker.cfg
