FAQ & Troubleshooting

Mod not loading after install?

Make sure you have BepInEx 5.x installed correctly. The mod DLL should be in BepInEx/plugins/. Check BepInEx/LogOutput.log for errors. Ensure you're running a compatible game version.

How do I find my config file?

Config files are in BepInEx/config/ inside your Sun Haven game folder. Each mod has its own .cfg file. You can edit these with any text editor while the game is closed, or use in-game settings if the mod supports them.

Can I use multiple mods together?

Yes! All mods on this hub are designed to work together with no conflicts. Some even have direct integration — for example, Senpai's Chest automatically excludes already-donated museum items when S.M.U.T. is installed.

How do I update a mod?

Simply replace the old DLL file in BepInEx/plugins/ with the new version. Your config settings and save data are preserved automatically. If using r2modman/Thunderstore, updates are handled for you.

My settings reset after an update?

If a mod adds new config options, BepInEx may regenerate the config file. Your existing settings should be preserved, but new options will use their defaults. Check the .cfg file to verify your preferences.
