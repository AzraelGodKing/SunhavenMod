Fishing Mod

Trinket FortuneFishing Trinket Bias

The sea rewards the patient

+5% per 10% aquarium (default)
v1.0.1

Trinket Fortune increases the odds of unowned fishing trinkets dropping as you complete the museum aquarium. The more you donate to the aquarium, the kinder the waters—that last relic you seek drifts closer with each cast. Fishing for that final trinket becomes less frustrating.

Fill the aquarium; the ocean favors you.

Features

🏛

Museum-Aware

As you donate more aquarium trinkets, the drop odds for trinkets you don't own yet increase. Your progress is rewarded.

⚖️

Configurable

Adjust the bonus strength and minimum museum progress threshold. Enable or disable without uninstalling.

📊

S.M.U.T. Integration

Works with S.M.U.T. for donation data. With HavenDevTools, see your missing trinkets in Azrael's Mods.

Configuration

BepInEx/config/com.azraelgodking.trinketfortune.cfg
Setting Default Description
Enabled true Turn Trinket Fortune on or off
MuseumProgressBonusPercent 5 Bonus to unowned trinket odds per 10% aquarium completion (e.g. 5 = +5% per 10%)
MinimumMuseumProgress 0.2 No bonus below this aquarium progress (0.2 = 20%). Prevents bonus at very low completion.

Edit the file above to change settings, then restart the game.

Installation

📦

1. Install BepInEx

Install BepInEx 5.x for Sun Haven if you haven't already.

📥

2. Download Trinket Fortune

Get TrinketFortune.dll from Thunderstore or the Mod Hub.

📁

3. Install the mod

Place the DLL in BepInEx/plugins/TrinketFortune/ (or BepInEx/plugins/).
