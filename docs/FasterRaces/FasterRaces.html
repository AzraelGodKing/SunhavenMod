Quick Mod

Faster RacesConfigurable Movement Speed

One speed bonus, no double-dipping

+25% default
v1.0.0

Faster Races adds a configurable movement speed bonus for your character. When used with Haven's Birthright, it automatically disables Haven's Birthright movement speed bonuses (e.g. Amari Cat, Amari Bird Tailwind) so you get a single, consistent speed boost from Faster Races instead of stacking both.

One speed bonus, no double-dipping — HB skips its speed buffs when Faster Races is loaded.

Features

📢

Configurable Speed

Set the bonus percentage in the config (default +25%). Enable or disable the mod without uninstalling.

⚔️

Haven's Birthright Aware

When both mods are installed, HB skips its own movement speed buffs. Speed penalties (e.g. Amari Dog, Naga) still apply.

🎯

All Races

Same bonus for every character. Works standalone or alongside racial mods.

Configuration

BepInEx/config/com.azraelgodking.fasterraces.cfg
Setting Default Description
Enabled true Turn the movement speed bonus on or off
SpeedBonusPercent 25 Percentage added to movement speed (e.g. 25 = +25%)

Edit the file above to change settings, then restart the game or use BepInEx config reload if supported.

Installation

📦

1. Install BepInEx

Install BepInEx 5.x for Sun Haven if you haven't already.

📥

2. Download Faster Races

Get FasterRaces.dll from the repo releases or Thunderstore.

📁

3. Install the mod

Place the DLL in BepInEx/plugins/FasterRaces/ (or BepInEx/plugins/).

Works great with

⚔️

Haven's Birthright

Racial bonuses and abilities; speed buffs are automatically skipped when Faster Races is loaded
