# The Vault

Secure storage for seasonal tokens, community tokens, and keys in Sun Haven.

## Features

- **Auto-Deposit** - Automatically stores tokens and keys when picked up
- **Per-Character Saves** - Separate vaults for each save file
- **Encrypted Storage** - Your currencies are securely stored
- **Shop Integration** - Seamlessly spend from the vault at shops
- **Door Integration** - Use keys directly from the vault

## Supported Currencies

- Seasonal tokens (Spring, Summer, Fall, Winter)
- Community tokens
- Various keys

## Installation

1. Install BepInEx 5.x
2. Place `TheVault.dll` in `BepInEx/plugins/`
3. Launch the game

## Configuration

Edit `BepInEx/config/com.azraelgodking.thevault.cfg` to customize settings.
