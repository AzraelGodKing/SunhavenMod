# Faster Races

Adds a **configurable movement speed bonus** for your character. When used with **Haven's Birthright**, this mod disables Haven's Birthright movement speed bonuses so you don't get double speed—you get one consistent bonus from Faster Races instead.

## Features

- **Configurable speed** – Set the bonus percentage in the config (default +25%).
- **Compatible with Haven's Birthright** – If both mods are installed, Haven's Birthright will not apply its own movement speed bonuses (e.g. Amari Cat, Amari Bird Tailwind). Speed penalties from Haven's Birthright (e.g. Amari Dog, Naga) still apply.

## Configuration

Edit `BepInEx/config/com.azraelgodking.fasterraces.cfg`:

- **Enabled** – Turn the speed bonus on or off (default: true).
- **SpeedBonusPercent** – Percentage added to movement speed (e.g. 25 = +25%, default: 25).

## Requirements

- BepInEx 5.x (Sun Haven)
- Sun Haven

## Optional

- **Haven's Birthright** – Works best together; HB will skip its speed buffs when Faster Races is loaded.
